# Ganesh Utsav 2026 Interactive Web Portal

An interactive, responsive single-page web portal designed for **Vinayaka Chavithi (Ganesh Utsav 2026)** celebrations.

## Features
- **Canvas Physics Particle Engine:** Gentle falling animation of modaks (`🥟`) and traditional flowers (`🌸`, `🌺`, `🌼`, `🏵️`).
- **Parallax Hero Banner:** High-impact hero header with live devotional background music controls.
- **Embedded Google Forms Portal:** Switch seamlessly between 4 event forms without leaving the site:
  1. Pooja & Prasadam Registrations
  2. Idol & Laddu Sponsorship Lottery Entry
  3. Cultural & Sports Performance Registration
  4. Daily Volunteer Roster Sign-Up
- **Festival Significance Timeline:** Explaining the 7-day spiritual and cultural value of Ganeshotsav.
- **Photo Gallery:** Showcase grid for community celebrations.

## 🚀 How to Publish on GitHub Pages (Step-by-Step)

1. **Create a GitHub Repository:**
   - Go to [GitHub New Repository](https://github.com/new).
   - Name your repo: `ganesh-utsav-2026` (or `<your-username>.github.io`).
   - Select **Public** and click **Create repository**.

2. **Upload Code:**
   - Upload `index.html` and `README.md` into the main branch of your repository.

3. **Enable GitHub Pages:**
   - Go to your repository **Settings** tab.
   - Click **Pages** in the left sidebar menu under *Code and automation*.
   - Under **Build and deployment** > **Branch**:
     - Select `main` (or `master`) branch.
     - Select folder `/ (root)`.
   - Click **Save**.

4. **Access Your Live Portal:**
   - Within 1–2 minutes, GitHub will generate your live site URL:
     `https://<your-github-username>.github.io/ganesh-utsav-2026/`
